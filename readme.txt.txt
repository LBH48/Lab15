Домашнее задание: Среднее значение положительных элементов массива, 
расположенных по нечетным индексам.

Описание программы:
Программа запрашивает количество элементов массива, затем сами элементы. 
Находит сумму и количество положительных элементов на нечетных индексах (1, 3, 5...). 
Выводит среднее значение.

Компиляция:
Проект создан в Visual Studio 2022. Язык C.
