## 📌 Задание (Домашняя работа)
С одномерным массивом, состоящим из `n` вводимых с клавиатуры целых чисел, выполнить следующие вычисления:
**Среднее значение положительных элементов массива, расположенных по нечетным индексам.**

---

## ⚙️ Входные и выходные данные

* **Входные данные:**
  * `n` (int): количество элементов массива.
  * `arr[n]` (int): сами элементы массива (целые числа).
* **Выходные данные:**
  * `sum` (int): накопленная сумма положительных элементов на нечетных индексах.
  * `count` (int): количество таких элементов.
  * `average` (float): вычисленное среднее значение.

---

## 🧮 Контрольный пример

Возьмем массив из 5 элементов, введенных пользователем:
`10, 13, 2345, 5, 9876`

**Ручной расчет:**
1. Индексы элементов: `0, 1, 2, 3, 4`.
2. Нечетные индексы: `1, 3`.
3. Элементы на этих индексах: `13` и `5`. Оба положительные.
4. Сумма: `13 + 5 = 18`. Количество: `2`.
5. Среднее: `18 / 2 = 9.00`.

**Ожидаемый результат:** Программа должна вывести `Среднее значение: 9.00`.

---

## 📊 Описание алгоритма

1. **Начало** → Инициализация переменных, запрос количества элементов `n`.
2. **Цикл ввода:** `i` от 0 до `n-1`. Пользователь вводит элементы массива.
3. **Цикл обработки:** `i` от 1 до `n-1` с шагом `+2` (перебор только нечетных индексов).
   * Если `arr[i] > 0` (элемент положительный):
     * Добавить `arr[i]` к сумме `sum`.
     * Увеличить счетчик `count`.
4. **Проверка деления на ноль:** Если `count > 0`:
   * Вычислить среднее: `average = (float)sum / count`.
   * Вывести результат.
   * Иначе: вывести сообщение, что таких элементов нет.
5. **Конец**.

---

## 💻 Структура программы

Программа реализована в процедурном стиле:
* `int main(void)`: Управляет вводом/выводом, содержит основной цикл обработки массива.
* Используется приведение типов `(float)` для корректного деления и получения дробной части среднего значения.
